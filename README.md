# Restaurant Menu - Java Console Project

This is a simple console-based Java application that simulates a basic restaurant menu. It was developed as part of a college assignment and is intended for educational purposes.

## Technologies

- Java
- IntelliJ IDEA

## Features

- Displays a list of menu items
- Allows user to select dishes
- Calculates the total price of the order
- Console interaction
